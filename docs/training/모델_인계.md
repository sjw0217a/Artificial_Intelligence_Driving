## 2. 성능 (최종 평가: 고른 뒤 처음 쓰는 시드로 한 번만)

시드 2026111721~32, 조건마다 시드 3개 × 100 Episode. 이 결과를 본 뒤로는 모델을 바꾸지 않았다.

| 조건 | 충돌 | 신호 위반 | 경로 이탈 | 시간초과 | 복잡 구간 |
|---|---|---|---|---|---|
| 평시 | 0/300 | 0 | 0 | 0 | 14.91초 |
| 크리스마스 | 2/300 | 0 | 0 | 0 | 21.89초 |
| 크리스마스 + 교통량 1.3배 (학습에 안 쓴 조건) | 5/300 | 0 | 0 | 1 | 25.39초 |
| 크리스마스 + 버스 3배 | 12/300 (4.0%) | 0 | 0 | 0 | 22.74초 |

같은 시드에서 세 모델 비교 (1,200 Episode 합계):

| 모델 | 충돌 | 신호 위반 Episode | 경로 이탈 | 실패 | 복잡 구간 |
|---|---|---|---|---|---|
| BC | 38 (3.2%) | 125 (10.4%) | 35 | 155 | 21.48초 |
| **BC + DAgger (최종)** | **19 (1.6%)** | **0** | **0** | **20** | **21.19초** |
| BC + PPO (3차) | 25 (2.1%) | 10 (0.8%) | 0 | 33 | 22.71초 |

## 3. 데이터 수집 명령

```bash
conda activate sumo-rl
python collect_pomdp_data.py --model models/strict_bc_dagger.pt --episodes 1000 --workers 8 --seed 300 --name strict_normal
python collect_pomdp_data.py --model models/strict_bc_dagger.pt --episodes 1000 --workers 8 --seed 400 --christmas --name strict_xmas
```

- `--model`만 주면 PPO 형식으로 자동 판별한다. 결정적 행동이 기본이고, 다양성이 필요하면 `--stochastic`을 쓴다.
- **`--seed`는 300 이상을 쓸 것.** 학습 데이터는 141~173을 썼다.
- 수집 기록의 `event`에 `red_light`(적신호에 정지선 통과)가 들어간다.
- 1 Episode는 약 370~400 step이다 (1 step = 0.5초).

## 4. 학습 방법 요약

1. **expert(규칙 기반 운전자)**, `utils/rule_policy.py`: 학습 정답을 만들 때만 쓴다.
   - IDM 가감속, 적·황신호에서 정지 (관측 [31]·[32])
   - 경로상 필요할 때만 차선 변경 (틈 수락)
   - 정류장에 버스가 서 있으면 옆 차로로 추월
2. **시연:** 평시 400 + 크리스마스 400 + 크리스마스·버스 3배 200 Episode
3. **BC:** PPO 네트워크를 시연에 지도학습
4. **DAgger 3라운드:** 학생이 운전한 상태에 expert의 정답을 붙여 추가 (라운드당 400 Episode, β = 0)
5. **비교 후보 PPO:** 같은 BC에서 미세조정, 3번 시도. 신호 위반이 1% 안팎 남아 탈락

다시 만들기: `bash scripts/training/train_strict_model.sh`

## 5. 반드시 공개할 것

- expert는 SUMO 내부 정보를 쓴다. 최종 모델은 관측 38칸만 보고 혼자 운전한다.
- ego의 SUMO 보조(적신호 정지, 교차로 양보, 차선변경 판정)는 모두 껐다. 경로 안내는 지도 수준(다음 회전 방향과 거리)만 준다.
- 관측 31 → 38차원: [31]·[32] 신호와 정지선 거리, [33]·[34] 측면 레이더, [35]·[36] 다음 회전 방향과 거리, [37] 80 m 앞 정류장 버스 정차
- 크리스마스·버스 3배 조건은 학습에도 썼다. 처음 보는 조건은 크리스마스 ×1.3이다.
- 수업 코드 수정: 충돌을 도착으로 세던 버그, 시간초과 처리, 평가 시드 분리(`--eval-seed`), 신호 위반 감지
- 최종 모델은 expert보다 낫지 않다: 시간·신호 준수는 같은 수준, 충돌은 expert보다 많다 (검증 1,200 Episode에서 1회 대 21회)
