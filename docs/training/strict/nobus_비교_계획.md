# 관측 [37] 효과 비교: 계획 (결과를 보기 전에 씀)

## 왜 하는가

예전 발표 영상은 BC와 최종 모델(BC + DAgger)을 같은 교통에서 나란히 보여 주며 "BC는 버스 뒤에 갇히고 최종 모델은 추월한다"고 설명했다. 그런데 BC도 관측 [37](정류장 버스 정차)을 받고 expert의 추월 시연을 똑같이 배웠다. 최종 평가에서 버스를 만났을 때 추월 비율도 BC 63% · 81%, 최종 모델 53% · 78%(크리스마스 · 버스 3배)로 비슷하다. 영상은 BC가 우연히 갇힌 장면 하나였고, 두 모델의 실제 차이(신호 위반 125 → 0, 경로 이탈 35 → 0)를 보여 주지 못했다.

그래서 버스 추월 장면은 "추월 정보 [37]이 있을 때와 없을 때"를 비교한다.

## 비교 모델

| 모델 | 파일 | 관측 | 학습 |
|---|---|---|---|
| 최종 모델 | `models/strict_bc_dagger.pt` | 38칸 | expert 시연 → BC → DAgger 3라운드 |
| [37] 없음 | `models/strict_nobus_dagger.pt` | 37칸 ([37]만 뺌) | 같음 (`scripts/training/train_strict_nobus.sh`) |

[37] 없는 모델은 최종 모델과 시연 Episode 수, 조건 비율, 수집 시드(141~173), BC 설정, DAgger 라운드가 모두 같고 `BUS_STOP_FLAG=0` 하나만 다르다. expert는 버스 정차를 SUMO에서 직접 보므로 시연에는 추월이 그대로 들어간다. 학생만 "앞에 선 차가 정류장 버스인지"를 모른다.

## 평가

- 모델: 위 두 모델에 더해 BC(`models/strict_bc.pt`), BC + DAgger β 쿨다운(`models/strict_bc_dagger_beta.pt`), BC + PPO 3차(`models/strict_bc_ppo3.pt`)도 같은 시드로 돌린다. β 쿨다운은 최종 평가 시드(2026111721~32)로 돌린 적이 없고, 그 시드는 다시 쓰지 않으므로 네 모델(BC, BC + DAgger, β 쿨다운, BC + PPO)을 같은 교통에서 비교하려면 새 시드가 필요하다. 공식 수치는 최종 평가 그대로 두고, 이 결과는 비교용으로만 쓴다.
- 시드: 한 번도 쓰지 않은 443001~443012 (평시 01~03, 크리스마스 04~06, 크리스마스 ×1.3 07~09, 크리스마스 + 버스 3배 10~12), 시드마다 100 Episode, 조건마다 300 Episode. 다섯 모델이 같은 시드라 Episode마다 교통이 같다.
- 지표: 충돌 · 신호 위반 · 경로 이탈 · 시간초과 · 실패, 실패 % 평균 ± 표준편차(시드 묶음 3개, 각 400 Episode), 복잡 구간 시간, 버스를 만난 Episode 중 추월 비율과 그때의 복잡 구간 시간.
- 추월: 정류장에 버스가 서 있는 동안 S1b에서 1번 이상 차로에 있었던 Episode (`eval_section_time.py`의 `bypass`).
- 이 평가는 최종 모델을 고르는 데 쓰지 않는다. 최종 모델은 바뀌지 않는다.
- 실행: `zsh scripts/training/strict_nobus_eval.sh` → `docs/training/strict/nobus_eval/`

## 영상 장면 고르는 규칙

크리스마스 장면 0부터 차례로 두 모델을 돌려(`record_episode.py --search`) 아래를 모두 만족하는 **첫 장면**을 쓴다.

1. 두 모델 모두 충돌 · 신호 위반 없이 도착
2. 두 모델 모두 정류장에 선 버스를 만남
3. 두 모델이 같은 스텝에 복잡 구간(S1)에 들어감 (같은 교통에서 출발)
4. 최종 모델이 추월함

[37] 없는 모델이 그 장면에서 무엇을 하든 그대로 보여 주고, 영상 옆에 위 평가의 추월 비율을 함께 적는다. 영상 하나로 두 모델을 판단하지 않게 하기 위해서다.

## 결과 (위 계획대로 돌린 뒤 덧붙임)

자세한 표와 해석: [../학습_과정_기록.md](../학습_과정_기록.md) 12.8절, 원본 [nobus_stats.txt](nobus_stats.txt).

- [37]을 빼면 충돌이 1.5% → 9.1% (같은 Episode에서 한쪽만 충돌: 최종 11, [37] 없음 102). 추월은 64% → 55% (한쪽만 추월: 34 대 10, p = 0.0004). 복잡 구간 시간은 줄지 않았다 (둘 다 버스를 만난 Episode에서 차이가 표준오차 안).
- 네 모델: 실패 BC 156, BC + DAgger 22, β 쿨다운 18, BC + PPO 28 (각 1,200 Episode).
- 영상 장면: 규칙에 맞는 장면은 4, 25, 91, 121, 145, 156이고 첫 장면 4는 두 모델 모두 추월한 장면이다 (최종 41.0초, [37] 없음 17.0초). 이 장면은 측정된 차이(충돌)를 보여 주지 못해 비교 영상을 만들지 않았다. 규칙을 바꿔 다른 장면을 고르지도 않았다.
